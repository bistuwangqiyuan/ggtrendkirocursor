# Product Overview

This is a **Netlify Platform Starter** demonstrating Astro.js capabilities with Netlify Core Primitives.

## Purpose

Showcase how Astro websites can leverage Netlify's platform features:

- Streaming SSR (Server-Side Rendering)
- Edge Functions for geo-based routing
- Image CDN optimization
- Netlify Blobs for data storage
- On-demand revalidation and stale-while-revalidate caching

## Key Features

- **Revalidation**: Cache invalidation and fine-grained cache control
- **Image CDN**: Optimized image delivery
- **Edge Functions**: Geo-based content routing (e.g., Australia vs. non-Australia)
- **Blobs Storage**: Interactive shape generator with persistent storage using Netlify Blobs

## Target Audience

Developers looking to build modern, performant Astro sites on Netlify with advanced platform features.
